# Módulos adaptados de RoutingTales

Origen: Passport-Hotel/src/lib/modules/{info,video,question}, componentes compartidos y utilidades correspondientes. Se mantienen los reproductores y sus interacciones; las rutas de medios, guardado, finalización y estilos se adaptan a Isometric. El formulario común, importación JSON, validación y progreso viven en el nivel superior de modules. No se llaman las API ni los servicios de cuentas de RoutingTales.
